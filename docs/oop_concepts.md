# OOP Concepts Applied in "Book My Ticket"

This document provides a comprehensive mapping of all Object-Oriented Programming (OOP) concepts visibly implemented in the **Book My Ticket** movie ticket booking system for course **22IT321 Object Oriented Programming**.

| OOP Concept | Source File | Class / Method | Concrete Implementation Details |
|---|---|---|---|
| **Encapsulation** | `src/com/bookmyticket/model/Person.java`<br>`src/com/bookmyticket/model/Seat.java`<br>`src/com/bookmyticket/model/Movie.java`<br>`src/com/bookmyticket/model/Booking.java` | Private fields with public getters and setters across all model classes. | All entity state variables (e.g., `Seat.seatNumber`, `Seat.basePrice`, `Seat.booked`, `Movie.title`, `Booking.totalAmount`) are marked `private`. Access and modifications are strictly governed through validated getters and setters, shielding internal representations from unauthorized tampering. |
| **Abstraction (Abstract Class)** | `src/com/bookmyticket/model/Person.java` | `public abstract class Person`<br>`public abstract String getRole();` | Defines an abstract person hierarchy with common attributes (`name`, `phoneNumber`). Mandates that concrete roles (`Customer` and `Admin`) supply their specific role definitions without instantiating generic person entities. |
| **Abstraction (Abstract Class)** | `src/com/bookmyticket/model/Seat.java` | `public abstract class Seat implements Bookable`<br>`public abstract double getPrice();`<br>`public abstract String getSeatType();` | Establishes the blueprint for cinema seats. Abstract methods `getPrice()` and `getSeatType()` defer category-specific pricing logic to derived classes while encapsulating seat state and booking actions. |
| **Abstraction (Interface)** | `src/com/bookmyticket/model/Bookable.java` | `public interface Bookable { void book(); void cancel(); boolean isBooked(); }` | Specifies a behavioral contract for reservable resources. Implemented by both `Seat` (individual seat reservation) and `Booking` (overall ticket lifecycle reservation). |
| **Inheritance** | `src/com/bookmyticket/model/Customer.java`<br>`src/com/bookmyticket/model/Admin.java` | `public class Customer extends Person`<br>`public class Admin extends Person` | `Customer` and `Admin` extend the abstract base class `Person`, reusing its constructor, name, and phone state while adding role-specific methods (such as `Admin.authenticate`). |
| **Inheritance** | `src/com/bookmyticket/model/RegularSeat.java`<br>`src/com/bookmyticket/model/PremiumSeat.java` | `public class RegularSeat extends Seat`<br>`public class PremiumSeat extends Seat` | `RegularSeat` and `PremiumSeat` extend the abstract `Seat` class, inheriting core seat coordinate and availability logic while specializing tier behaviors. |
| **Polymorphism (Overriding)** | `src/com/bookmyticket/model/RegularSeat.java`<br>`src/com/bookmyticket/model/PremiumSeat.java` | `@Override public double getPrice()`<br>`@Override public String getSeatType()` | `RegularSeat.getPrice()` returns standard base price; `PremiumSeat.getPrice()` overrides this to dynamically append a luxury surcharge (`basePrice + 50.0`). When `BookingService` tallies seats, `seat.getPrice()` resolves polymorphically at runtime. |
| **Polymorphism (Overriding)** | `src/com/bookmyticket/model/Customer.java`<br>`src/com/bookmyticket/model/Admin.java` | `@Override public String getRole()` | Overrides `Person.getRole()` to return `"Customer"` and `"Admin"`, respectively. Also overrides `toString()` across entities for polymorphic display. |
| **Polymorphism (Overloading)** | `src/com/bookmyticket/service/BookingService.java` | `calculateTotal(List<Seat> seats)`<br>`calculateTotal(List<Seat> seats, double discountPercentage)`<br>`calculateTotal(int seatCount, double unitPrice)` | Multiple versions of `calculateTotal` share the same method name but differ in parameter count and types, demonstrating compile-time (static) polymorphism for standard, discounted, and bulk pricing. |
| **Exception Handling (Custom Exceptions)** | `src/com/bookmyticket/exception/SeatAlreadyBookedException.java`<br>`src/com/bookmyticket/exception/InvalidInputException.java` | Custom checked exceptions extending `java.lang.Exception`. | Thrown during business rule violations (e.g., trying to reserve an occupied seat or providing empty names/invalid 10-digit phone numbers). |
| **Exception Handling (Try-Catch-Finally)** | `src/com/bookmyticket/util/FileManager.java`<br>`src/com/bookmyticket/ui/LoginFrame.java`<br>`src/com/bookmyticket/ui/SeatSelectionFrame.java` | `try { ... } catch (IOException e) { ... } finally { reader.close(); }` | Explicit `try-catch-finally` blocks ensure file streams are always closed safely even if I/O exceptions occur. Catches custom exceptions in UI frames and displays friendly `JOptionPane` dialogs. |
| **Threading (SwingWorker)** | `src/com/bookmyticket/service/BookingService.java` | `public void saveBookingsAsync()` using `new SwingWorker<Void, Void>()` | Heavy disk serialization of booking records is offloaded to a background worker thread. Keeps the Java Swing Event Dispatch Thread (EDT) completely responsive, preventing UI freezes. |
| **Concurrency / Synchronization** | `src/com/bookmyticket/service/BookingService.java` | `public synchronized Booking bookSeats(...) throws SeatAlreadyBookedException` | The critical section for checking seat availability and marking seats as reserved is `synchronized`. Prevents race conditions where two simultaneous requests could book the exact same seat. |
| **File Handling (Persistent Storage)** | `src/com/bookmyticket/util/FileManager.java` | `loadMovies()`, `saveMovies()`, `loadBookings()`, `saveBookings()` | Uses `BufferedReader`, `BufferedWriter`, `FileReader`, and `FileWriter` to read and write comma-separated value (CSV) text files in `data/movies.txt` and `data/bookings.txt`. Auto-creates files and seeds default movies on first launch. |
| **Collections Framework** | `src/com/bookmyticket/service/MovieService.java`<br>`src/com/bookmyticket/service/BookingService.java`<br>`src/com/bookmyticket/model/Show.java` | `List<Movie> movies = new ArrayList<>()`<br>`Map<String, Booking> bookings = new HashMap<>()`<br>`List<Seat> selectedSeats = new ArrayList<>()` | Uses `ArrayList` for ordered lists of movies, shows, and seats. Uses `HashMap<String, Booking>` for fast $O(1)$ lookups of bookings by their unique booking ID. |
| **Event Handling** | `src/com/bookmyticket/ui/LoginFrame.java`<br>`src/com/bookmyticket/ui/MovieListFrame.java`<br>`src/com/bookmyticket/ui/SeatSelectionFrame.java`<br>`src/com/bookmyticket/ui/AdminFrame.java` | `ActionListener`, `ListSelectionListener`, `WindowListener` | `ActionListener` handles button clicks and seat selection toggles; `ListSelectionListener` updates show timings when a movie row is clicked; `WindowAdapter` (`windowClosing`) guarantees persistent state flush on app exit. |
